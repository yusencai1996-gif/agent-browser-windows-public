# Changes from huashu-chrome

The original MIT copyright and license are retained in LICENSE. Derived from commit b979984ebf0b4dc13b303c1c171823c7afab3e8f.

Windows bridge integration adds authenticated instance/task control, explicit tab ownership, navigation readiness and protected page policies. Agent tab groups use the project name. A trusted extension overview adds exact-target memory previews, user takeover/return and human windows. Runtime sender checks and URL normalization are hardened; screenshots no longer fall back to a different visible tab.

The public alpha replaces upstream/downstream personal artwork with a code-generated neutral window icon. Optional OpenCLI is a separate unmodified extension under its own Apache-2.0 license.
